Álbum Mundial 2026

Claude Monitor

App de bandeja del sistema para Windows que muestra en tiempo real el % de uso de Claude.ai en la barra de tareas. Icono circular que cambia de color según el consumo (verde → ámbar → rojo), tooltip con uso de las últimas 5 horas y 7 días, ventana de detalles con arcos de progreso animados, y auto-detección de sesión leyendo la cookie directamente desde el SQLite de Chrome o Edge.

03
SurgCards

PWA de flashcards para residentes de cirugía. Mazos temáticos con cirugías precargadas (colecistectomía, apendicectomía, reemplazo valvular…), 3 tipos de tarjetas por cirugía: conceptos, instrumental y paso a paso. Algoritmo de repetición espaciada (SRS), modo quiz A/B/C/D, estadísticas de racha y retención. Funciona offline con persistencia en IndexedDB.

Next.js React TypeScript Tailwind CSS IndexedDB PWA

WhatsApp AI Bot

Bot conversacional conectado a WhatsApp vía Meta Cloud API. Recibe mensajes por webhook, mantiene historial de conversación por número de teléfono (hasta 20 mensajes) y responde con personalidad propia — amigable, con humor y toque sarcástico — usando inferencia ultra-rápida con Llama 3.3 70B a través de Groq API.
